Privacy policy

Supernova · last updated 11 November 2026

Supernova is a personal tool used only by its author, with the author's own Google account. No one else's data is collected.

What it accesses

  • Gmail: reads messages, and saves drafts. It never sends email; the author sends drafts themselves.
  • Google Calendar: reads free/busy times, and the events of the calendars the author chooses.
  • Google Sheets: reads spreadsheets, never changes them.

How it is used

The data is used only to remind the author of what needs attention and to plan the week. It is processed on the author's own computer. Parts of it are sent to the AI model providers the author has configured (Mistral AI, Anthropic) to be read and summarised, under those providers' API terms, and are not kept by Supernova anywhere else.

Nothing is sold, shared with anyone, used for advertising, or used to train AI models. Access tokens are stored only on the author's computer.

Google API data

Supernova's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions.
